# music web

## Import album data while organizing uploads

On the **Uploads** page, open **Batch organize audio** and expand **Get album data from MusicBrainz** for a group. Search by album and optional artist, choose the correct release after checking its date, country and track list, then apply its album fields. Existing track titles and performers are changed only when a title or disc/track position maps uniquely; uncertain tracks stay as they were.

The optional **Import and select cover** action downloads the selected release's front artwork into the existing image library. It does not automatically replace a cover already assigned to an album, and the usual review and publish step is still required. Artwork may be copyrighted; import it only when you have the right to use it. Metadata and artwork links are shown in the dialog.
